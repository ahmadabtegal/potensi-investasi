PORTAL PELUANG DAN POTENSI INVESTASI KOTA TEGAL

Isi paket:
- index.html: frontend website investasi (menggunakan backend Apps Script yang sudah dikonfigurasi di file ini).
- assets/logo-kota-tegal.png: lambang Kota Tegal untuk header.
- assets/logo-dpmptsp.png: logo DPMPTSP untuk header.
- assets/favicon.png dan assets/favicon.ico: favicon lambang Kota Tegal.

Pemasangan GitHub Pages:
1. Unggah index.html dan folder assets ke root repository (struktur folder jangan diubah).
2. Commit/push ke branch yang dipakai GitHub Pages.
3. Muat ulang situs dengan Ctrl+Shift+R.
4. Jika favicon belum berubah, tunggu cache browser diperbarui atau hapus cache favicon.

Tidak perlu mengganti Code.gs atau Google Sheet untuk perubahan logo ini.
